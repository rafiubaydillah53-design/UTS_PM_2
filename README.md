## 📌 Deskripsi Aplikasi

Aplikasi ini merupakan aplikasi jadwal kuliah yang dilengkapi dengan fitur AI Assistant. 
Aplikasi ini bertujuan untuk membantu pengguna dalam mengelola jadwal perkuliahan serta memberikan informasi dan motivasi harian melalui teknologi AI.

---

## 🎯 Tujuan

Tujuan dari pembuatan aplikasi ini adalah:
- Mempermudah pengelolaan jadwal kuliah
- Mengimplementasikan teknologi AI dalam aplikasi mobile
- Meningkatkan pengalaman pengguna (User Experience)

---

## ✨ Fitur Utama

- 📅 Menampilkan jadwal kuliah harian
- 📋 Menampilkan seluruh jadwal kuliah
- 🤖 AI Assistant (Milo) untuk memberikan motivasi dan informasi
- 💬 Fitur chat dengan AI (Conversational UI)
- 🔘 Tombol akses cepat AI (Floating Action Button)

---

## 🛠️ Teknologi yang Digunakan

- Flutter / Android Studio
- Firebase / API
- Figma (untuk desain UI/UX)
